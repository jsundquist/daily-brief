# Interest profile

Edit freely. The daily-brief skill reads this every time. Topics are in priority order; the brief gives each topic its own section.

## AI engineering and coding agents
**Care about:** how people actually work with coding agents (workflows, context, review, verification), updates to Claude Code and Anthropic's developer products, MCP and agent tooling, agent security and failures, how to design goals, skills and design-system context for agents, always-on and long-running agents, practical lessons from real deployments, new agent frameworks and dev tools. Opinion pieces count when they argue a concrete practice about AI-written code (open source, CI, review, recovery from agent mistakes).
**Skip:** vague "the future of work" opinion pieces with no concrete practice, funding-round chatter (that belongs under AI industry), case studies of agents in domains I do not work in (legal, finance, utilities, trading), product marketing, podcasts and videos unless they are about my own workflow.

## AI industry news
**Care about:** frontier model launches and what changed for coding and agents, AI safety evaluation and testing methods, major lab strategy and funding/IPO news, credible research claims and benchmarks.
**Skip:** gossip, personal-drama stories, rumours with one source, model showcase demos in science, finance or law, low-level training or inference research (4-bit training, KV cache, TPU libraries) unless it changes what I can run or use.

## Security
**Care about:** breaches and vulnerabilities affecting tools I might use (npm, PyPI, Linux, cloud providers, AI tools), supply-chain attacks and defences, security of AI agents.
Secrets-management and agent-credential tooling (1Password for agents, secret scanning) and AI security tools I could run myself (Codex Security, Airgorah-style pentest tools) also count.
**Skip:** vendor product launches, breaches of companies and services I would never touch (a chip maker's employee data, for example).

## JavaScript and Node
**Care about:** Node/Bun/Deno releases, TypeScript, major framework and tooling releases, browser/web platform changes, npm ecosystem issues.
**Skip:** minor point releases, WebGL/graphics demos unless unusually notable.

## Platform, DevOps and cloud-native
**Care about:** Kubernetes and CNCF projects, platform engineering (Backstage, IDPs), observability, CI/CD and making CI faster, IaC (OpenTofu/Terraform), self-hosted monitoring and ops tools (Uptime Kuma), concrete AWS and GitHub changes that affect how I work (Secrets Manager, Copilot model retirements), real incident write-ups and postmortems.
**Skip:** vendor feature announcements with no depth, conference intros and closing remarks, AI training cluster scheduling, CNCF contest and award announcements.

## Open-source tools and languages
**Care about:** new or surprising open-source tools I could use, especially self-hosted tools and developer-facing UI and framework libraries (UI SDK, the Console Framework), notable language/runtime news (Rust, Python, Go, Java).
**Skip:** one-off hobby projects, apps for niches I don't work in.

## Only if it is big
Enterprise IT, data centers and fintech. Include an item here only when it is a major story, never as a regular section.

# Interest profile

Edit freely. The daily-brief skill reads this every time. Topics are in priority order; the brief gives each topic its own section.

## AI engineering and coding agents
**Care about:** how people actually work with coding agents (workflows, context, review, verification), MCP and agent tooling, agent security and failures, practical lessons from real deployments, new agent frameworks and dev tools.
**Skip:** vague "the future of work" opinion pieces with no concrete practice, funding-round chatter (that belongs under AI industry).

## AI industry news
**Care about:** frontier model launches and what changed, major lab strategy and funding/IPO news, credible research claims and benchmarks.
**Skip:** gossip, personal-drama stories, rumours with one source.

## Security
**Care about:** breaches and vulnerabilities affecting tools I might use (npm, PyPI, Linux, cloud providers, AI tools), supply-chain attacks and defences, security of AI agents.
**Skip:** vendor product launches, breaches of companies and services I would never touch.

## JavaScript and Node
**Care about:** Node/Bun/Deno releases, TypeScript, major framework and tooling releases, browser/web platform changes, npm ecosystem issues.
**Skip:** minor point releases, WebGL/graphics demos unless unusually notable.

## Platform, DevOps and cloud-native
**Care about:** Kubernetes and CNCF projects, platform engineering (Backstage, IDPs), observability, CI/CD, IaC (OpenTofu/Terraform), real incident write-ups and postmortems.
**Skip:** vendor feature announcements with no depth, conference intros and closing remarks.

## Open-source tools and languages
**Care about:** new or surprising open-source tools I could use, notable language/runtime news (Rust, Python, Go, Java).
**Skip:** one-off hobby projects, apps for niches I don't work in.

## Only if it is big
Enterprise IT, data centers and fintech. Include an item here only when it is a major story, never as a regular section.
